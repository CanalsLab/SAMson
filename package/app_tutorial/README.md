# SAMson app tutorial (video)

* `SAMson_app_tutorial.mp4`: 8 min 12 s, 1920 x 1080, H.264 + AAC, narrated tour of the five steps of the app (`samson app`;
  guide: `../guides/03_app_guide.md`); `SAMson_app_tutorial.srt`: captions (English).
* `example_image/`: the image used in the video, `merge_C230524_ses-01_run-02_T2w.nii.gz`, with its SHA-256 checksum
  (`SHA256SUMS`), so that the tutorial can be repeated.

## Example image and data provenance

The video uses `merge_C230524_ses-01_run-02_T2w.nii.gz` (200 x 200 x 18 voxels, header voxel size 1.25 x 1.25 x 5.0 mm,
float32). It is not a subject of D1–D7 and has no manual mask: its voxel data match no image of the benchmark datasets
(compared voxel by voxel), and it is not the example bundled with the package (D1 subject A110123, 108 x 90 x 16). The authors have approved its
public release (2026-11-12) as the example image of the SAMson notebook, the app and this video tutorial. It is not used
in any benchmark.
